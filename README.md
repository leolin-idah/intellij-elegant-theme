# ElegantTheme for Jetbrains® IDEs

Elegant theme and color scheme for Jetbrains.

![elegant-theme example](https://raw.githubusercontent.com/yx208/elegant-theme/main/examples/code.png)

## Themes

| Theme | Description |
|---|---|
| Elegant Dark | The original dark theme, adjusted on top of JetBrains' Islands solid color scheme |
| Elegant Islands Dark | Refinements layered on JetBrains' official Islands Dark |
| Elegant Islands Light | Refinements layered on JetBrains' official Islands Light |
| Elegant Ink Light (Beta) | An eye-friendly ink-wash (水墨) light theme: ink-tone text and low-saturation traditional Chinese colors on warm rice-paper (宣纸) backgrounds — no pure black or white anywhere |

## Quick Start

1. Open [Settings]
2. Select [Appearance &amp; Behavior]
3. Select [Appearance]
4. Find the [Theme] dropdown menu, then select one of the Elegant themes (e.g. 'Elegant Dark' or 'Elegant Ink Light')

## FAQ

If you find that the color of the editor area does not match the theme color (which may appear as solid white), please follow these steps to check the Color Scheme.

1. Open [settings]
2. Select [Editor]
3. Select [Color Scheme]
4. Find the [Scheme] dropdown menu, then select the scheme matching your theme (e.g. 'Elegant Dark' or 'Elegant Ink Light')
